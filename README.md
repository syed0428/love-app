# 💖 Love App — A Romantic Keepsake Book

An interactive, responsive 3D chapter-by-chapter romantic keepsake web application built for Hayathi.

---

## ✨ Features

- 🎁 **Interactive Gift Box Intro**: An animated 3D ribbon box that opens to reveal the experience.
- 🔐 **Date-Gate Verification**: Memory verification gate unlocked by our special date (`28/01/2023`).
- 💍 **Playful Proposal Gate**: Dodging playful button interaction with celebratory confetti effects.
- 📖 **Authentic 3D Book Page-Turn Navigation**: True perspective foreshortening, physical rotation around the left spine fold, and dynamic curl shadow.
- 🖼️ **Photo Memory Wall**: Organic polaroid-style frames showcasing memories with captions and persistent IndexedDB upload support.
- 💌 **Love-Note Envelopes**: Click-to-reveal accordion-style romantic love letters.
- 📜 **Sealed Wax Letter**: Authentic wax-seal breaking reveal.
- 💫 **Couples Quiz & Sacred Duas**: Interactive trivia and Quranic reflection cards.
- 🌌 **Celestial Aesthetics**: Deep cosmic nebula backdrop, floating starlight particles, and smooth transitions.
- 📱 **Fully Responsive**: Optimized for iOS Safari, Android Chrome, mobile, tablet, and desktop viewports.

---

## 🚀 How to Run Locally

You can run this project with any local HTTP server:

### Using Python:
```bash
python -m http.server 8080
```
Then open your browser and navigate to:
```
http://localhost:8080
```

### Or using Node.js:
```bash
npx serve .
```
